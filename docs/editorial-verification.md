# 日本語・TOP・メールの追加検証（2026-10-07）

## 実装

分類 → 状況分析 → 原稿生成 → 自然な日本語への編集 → 機械検査と独立したAI校閲 → 合格した文だけ保存・表示。共通style.tsを全プロンプトで使用。追加質問は質問文だけ編集し、質問キー・型・内部理由を保持。無料／有料は全項目を対象にする。

編集は文字列のパスに限定し、構造・配列長・数値スコア・真偽値を変更できない。文章中の数字も順序ごと照合。原文と編集後を比較し、事実・否定・条件・助言の強さの変更をAI校閲で拒否。堅い用語、110文字超の一文、同一項目内の曖昧語の反復を機械検査。モデルには90文字以内を目安に指示。

最大3回まで指摘と直前の文章を引き継いで修正。未合格なら表示せず再試行可能なエラー。1ジョブ265秒の期限を持ち、300秒のルート・排他期限を超えない。各生成前にIDを発行し、結果・モデル・版・トークン・実行時間をサービス専用テーブルに保存。同じ診断・入力・プロンプトの成功済み段階を再利用し、失格した編集キャッシュは再利用対象から外す。
