# 第1開発単位の画面検証

2026-10-15 JST。Phase 5の実装済みデザインと比較し、TOPとすぐ相談を対象に確認した。残り7画面の全面置換は今回の対象外。

| 確認 | 結果 |
|---|---|
| PC 1440×1024 | 左ナビ、TOPの2カラム、主要CTA、4つの悩み、診断・前回の続き・料金へのリンクを表示。横幅1440=scrollWidth1440 |
| スマートフォン390×844 | 1カラム、下ナビ、相談画面の入力欄・同意文・停止中案内を表示。TOP主要CTA60px、カード88px、下ナビ65px、料金/ログイン44px以上 |
| 最小幅320×720 | TOP/相談ともscrollWidth320。横方向のはみ出しなし |
| 悩み別入口 | TOPの返信入口からtopic付き相談画面へ遷移。相談内のテーマ選択で片思い・恋人との距離・復縁の説明と任意項目が切り替わる |
| 800文字 | 800文字入力後の追加入力が増えないことをブラウザーで確認。サーバー上限も自動テストで検証 |
| 機能OFF | 準備中の案内を表示し、送信不可。AI呼出しなし |
| ブラウザーエラー | 完成ビルドのTOP/相談にはconsole errorなし |
| 既存料金ページ | リンク先への遷移を確認したが、ローカルに実Supabase設定がなく既存エラー画面となる。機能成功とは扱わない |

実回答・メール認証・引き継ぎ成功画面をブラウザーで通す外部E2Eは未実施。対応APIは隔離DBと合成providerで検証した。実機キーボード/IME、VoiceOver、ユーザーテストは未実施。相談文はブラウザー永続ストレージへ保存しないため、未送信の下書きはリロードで消える。
